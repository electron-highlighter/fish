# Electron Highlighter Fish

Electron Highlighter colors for fish shell.

## Usage

Copy the contents of `electron-highlighter.fish` into your `config.fish` and reload!

## Electron Highlighter Day (light)

A light variant is available as `electron-highlighter-day.fish` — copy its contents into your
`config.fish` the same way. It's generated from the [`palette`](https://github.com/electron-highlighter/palette)
repo; edit the palette there and run `npm run build` to regenerate.
